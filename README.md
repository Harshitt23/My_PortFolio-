A modern, responsive portfolio website to showcase my projects, skills, and achievements as a Full Stack Web Developer. Built with clean design principles, smooth animations, and optimized performance.

Responsive Design – Works seamlessly across all devices

Fast Performance – Optimized loading and smooth animations

# Getting Started
Prerequisites - Make sure you have the following installed:

Node.js
 (v14 or higher)

npm or yarn

# Installation

```bash
git clone https://github.com/Harshitt23/portfolio.git
cd portfolio
npm install
```

# Run Locally

```bash
npm start
```

The dev server starts at [http://localhost:3000](http://localhost:3000) and should open in your browser automatically.

> **Important:** Do not run `npm audit fix --force` on this project. It can replace `react-scripts` with a broken version and break `npm start`. If that happens, restore `react-scripts` to `5.0.1` in `package.json`, delete `node_modules` and `package-lock.json`, then run `npm install` again.

Production build (optional):

```bash
npm run build
```

# Deployment

Deployed on Vercel for fast, serverless performance.
To deploy your own version:

```bash
npm run build
vercel --prod
```
